Aplicação web para cálculo do **Índice de Massa Corporal (IMC)**, desenvolvida com HTML, CSS e JavaScript puro — sem frameworks ou bibliotecas externas.

---

## 📋 Sobre o Projeto

O IMC é um indicador utilizado para avaliar se uma pessoa está no peso adequado em relação à sua altura. Esta calculadora permite que o usuário informe seu peso e altura e receba instantaneamente seu IMC e a classificação correspondente.

---

## ✨ Funcionalidades

- Cálculo automático do IMC ao enviar o formulário
- Classificação do resultado em 6 categorias (da OMS)
- Validação de entrada com mensagem de erro amigável
- Aceita altura com vírgula ou ponto (ex: `1,75` ou `1.75`)
- Interface responsiva e limpa

---

## 📊 Tabela de Classificação

| IMC | Classificação |
|-----|--------------|
| Abaixo de 18,5 | Abaixo do peso |
| 18,5 – 24,9 | Peso normal |
| 25,0 – 29,9 | Sobrepeso |
| 30,0 – 34,9 | Obesidade grau I |
| 35,0 – 39,9 | Obesidade grau II |
| Acima de 40,0 | Obesidade grau III |

## 🚀 Como Executar

1. Clone o repositório:
```bash
git clone https://github.com/SEU_USUARIO/calculadora-imc.git
```

2. Acesse a pasta do projeto:
```bash
cd calculadora-imc
```

3. Abra o arquivo `index.html` no navegador.

> Não é necessário instalar nenhuma dependência.
